# Egg Chase 🥚🏃

একজন খেলোয়াড় দৌড়ায়, পেছনে একজন তাড়াকারী ডিম ছুঁড়ে মারে। ডিম এড়িয়ে যত দূর পারো দৌড়াও।

## ফিচার
- নিজের নাম দেওয়া যায়, নামটা এই browser এ মনে থাকে
- তিন লেনে ডিম এড়ানো, লেন বদলায় মসৃণভাবে
- পজ (P বা পজ বাটন)
- সেরা স্কোর browser এ সেভ থাকে
- কোনো image বা external library নেই, সব কোড দিয়ে আঁকা
- কোনো সার্ভার লাগে না, GitHub Pages এ সরাসরি চলে

## নিয়ন্ত্রণ
| কী | কাজ |
|---|---|
| ↑ / W | উপরের লেনে |
| ↓ / S | নিচের লেনে |
| P | পজ / চালিয়ে যাও |
| Enter | শুরু / আবার খেলো |
| মোবাইলে স্ক্রিনের উপরের অর্ধেকে ট্যাপ | উপরের লেন |
| মোবাইলে স্ক্রিনের নিচের অর্ধেকে ট্যাপ | নিচের লেন |

## ডিফল্ট নাম বদলানো
`js/main.js` ফাইলে `DEFAULT_NAME` লাইনে নতুন নাম লিখো। যে কেউ প্রথমবার খেললে এটাই আসবে।

## GitHub Pages এ চালানো
1. GitHub এ নতুন repository তৈরি করো (Public)।
2. এই ফোল্ডারের সব ফাইল ও ফোল্ডার (`index.html`, `css`, `js`, `README.md`) repository তে আপলোড করো।
3. Settings → Pages → Branch: `main`, Folder: `/ (root)` → Save।
4. কিছুক্ষণ পর `https://<username>.github.io/<repo>/` লিংকে গেম চালু হবে।
